# Security policy

## Supported versions

Security reports apply to the current released version of Tailwake for iPhone and iPad.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public GitHub issue. Use [GitHub private vulnerability reporting](https://github.com/naieeliao/tailwake/security/advisories/new) instead.

Include a clear description of the issue, the affected Tailwake version, steps to reproduce it, and any suggested mitigation. Please do not include passwords, SSH private keys, access tokens, MAC addresses, IP addresses, hostnames, or other private connection details.

We will review the report, investigate it, and work with you on a responsible disclosure plan.
